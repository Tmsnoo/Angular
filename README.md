# Mateusz Czech — portfolio

A responsive Angular portfolio for Mateusz Czech, with the original portfolio categories and photography:

- Portret
- Scena
- Gastro
- Nagrania Lektorskie

The photography is served from the author's existing `cdn.myportfolio.com` media library. The voice-over category embeds the video player used on the original portfolio.

## Development

```sh
npm install
npm start
```

Create a production build with `npm run build`.
